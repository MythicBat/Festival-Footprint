# 🎶Festival Footprint: Where Australia Grooves
A Vega-Lite data visualization exploring patterns, diversity, and climate influences of music festivals across Australia.

## 🌏 Project Overview
This project investigates **where music festivals cluster**, **which genres dominate**, and **how climate affects their timing**.
It visualizes five interconnected datasets using Vega-Lite charts, all embedded in a single, interactive webpage hosted via GitHub Pages.

🔗 **Live Demo:** [Festival Footprint](https://mythicbat.github.io/Festival-Footprint)

## 📊 Visualization Components
1. **Festivals by State/Territory (Choropleth Map)**: Geographic distribution of festivals across Australia using TopoJSON boundaries.
2. **Genre Mix (Bar Chart)**: Ranking of music genres by festival share, highlighting Australia's eclectic taste.
3. **Festival Seasonality (Radial Calendar)**: Month-by-Month donut chart revealing seasonal peaks (Nov-Mar).
4. **Festival Climate Sweet Spot (Bubble Plot)**: Integrates climate and festival density, revealing ideal conditions.
5. **Top Festival Capitals Leaderboard (Animated Race Bar)**: Dynamic race chart visualizing how capital cities compete over time.
6. **Interactive Festures**
   - State & Genre Filters.
   - Scroll-based storytelling.
   - Hover tooltips and smooth transitions.

## 🧩 Data Sources
- Souncheck: Australian Music Festivals: Australian festival listing 2022-23.
- Bureau of Meteorology (BOM): Climate averages by capital city
- Australian Bureau of Statistics (ABS): Choropleth Map

## 🛠️ Tech Stack
- **Vega-Lite v5** for visualizations
- **HTML5 / CSS3/ JavaScript** for page layout and styling
- **Pure.css** for responsive grid
- **GitHub Pages** for hosting
